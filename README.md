# WhatsApp Groups Hub Mz 🇲🇿

Plataforma web para descobrir e divulgar grupos WhatsApp, com foco em Moçambique.

## Estado atual

- Interface responsiva em estilo WhatsApp Dark Mode.
- Glassmorphism + neon verde.
- Pesquisa e filtros por categoria.
- Secções VIP, Moçambique e recentes.
- Formulário de publicação com URL de grupo e imagem por URL/upload.
- Contador de visitas no frontend.
- Painel administrativo demonstrativo.
- Persistência local via `localStorage` para protótipo.

## Próxima etapa: Supabase

Para produção, o projeto deve ligar grupos, aprovação, estatísticas, autenticação administrativa e armazenamento de imagens ao Supabase. A palavra-passe administrativa não deve permanecer no JavaScript do navegador em produção; deve ser substituída por autenticação segura e permissões/RLS.

## Executar

Pode abrir `index.html` diretamente para uma demonstração básica ou publicar o repositório como site estático.
